# SaaS Capability Map

## Operational plane

- Tenant and organization administration
- Fleet, vehicles, drivers, routes, trips, and dispatch
- Maintenance, inspections, work orders, incidents, and safety
- Documents, forms, notifications, reporting, and integrations

## SaaS control plane

- Tenant onboarding and provisioning
- Subscription plans, feature entitlements, usage metering, and billing integration
- Branding, support access, retention, exports, deletion, service status, deployment rings, and feature flags

## LeeWay intelligence plane

- Agent Lee orchestration and final synthesis
- Nexus tool routing
- Atlas tenant-scoped knowledge and memory
- Shield identity, authorization, tenant isolation, and approval enforcement
- Aura voice, vision, and media interaction
- Chronos scheduling, automation, CI/CD, and maintenance reminders
- QA MCP testing and Veritas scoring

## Deployment profiles

1. Shared SaaS for small and midsize operators.
2. Shared application with isolated tenant database for larger or regulated operators.
3. Dedicated enterprise application and data deployment for contractual or scale requirements.

## Status rule

A capability is not commercial-ready until implementation, automated tests, documentation, training, Agent Lee knowledge, authorization, tenant isolation, observability, and rollback evidence all pass.
