# REQ-0001: Enterprise Transit Foundation

The system shall:

- register and query transit vehicles;
- create, assign, start, and complete maintenance work orders;
- record service incidents;
- record vehicle inspections;
- manage employee forms;
- manage customer cases;
- provide an operations summary;
- create LeeWay execution receipts;
- expose governed HTTP endpoints;
- provide a browser dashboard;
- preserve replaceable SQL Server, Oracle, and Dataverse boundaries;
- include automated unit, integration, regression, security, and architecture tests.
