# Lesson 00: Agentic Developer Responsibility

You do not need to type every line. You must be able to explain and verify what the agents produce.

Before accepting a component, answer:

1. Why does it exist?
2. Which file owns it?
3. What enters it?
4. What leaves it?
5. What may it change?
6. What can fail?
7. Which test proves its behavior?

The compiler proves syntax and references. Tests prove selected behavior. Runtime checks prove the assembled system. None of them replaces your architectural review.
