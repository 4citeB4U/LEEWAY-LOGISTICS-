# LeeWay Enterprise Transit Hub Training System

This directory is the source authority for the controlled 300-page commercial training manual and its role-based curricula, labs, assessments, answer keys, and Agent Lee proctor instructions.

## Current status

The **manual architecture and exact 300-page budget are established**, but the final 300-page commercial manual is not yet complete. Each product phase must expand and validate the corresponding manual sections. The commercial release gate remains blocked until the manifest requirements are satisfied.

## Documentation modes

- Tutorials teach through guided learning experiences.
- How-to guidance supports specific tasks.
- Reference documents define fields, screens, APIs, roles, and commands.
- Explanation documents teach architecture, concepts, and decisions.

## Agent Lee

Agent Lee acts as an external instructor and proctor. He retrieves approved source material, identifies the learner role and product version, explains with citations, administers knowledge and practical assessments, evaluates against a rubric, and records a training receipt.
