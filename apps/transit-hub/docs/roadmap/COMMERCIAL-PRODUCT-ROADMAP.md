2. SQL Server tenant-aware persistence, migrations, procedures, and isolation tests.
3. Fleet, driver, route, dispatch, maintenance, inspection, incident, and document modules.
4. SignalR real-time operations, telemetry, notifications, and event contracts.
5. Agent Lee tool APIs, MCP server, tenant-scoped retrieval, approvals, and receipts.
6. Voice, vision, mobile, and hands-free workflows.
7. Trucking, school transportation, transit, shuttle, paratransit, and delivery profiles.
8. Subscription, metering, billing, support, deployment, monitoring, backup, and disaster recovery.
9. Complete and validate the 300-page manual, labs, assessments, instructor material, and Agent Lee proctor package.

## Release rule

No roadmap item is complete because code exists. Completion requires tests, runtime evidence, security review, tenant-boundary evidence, documentation, training updates, Agent Lee capability updates, rollback, and a LeeWay receipt.
