# Agent Lee Transit Hub Capability Package

This package makes LeeWay Enterprise Transit Hub an assigned external tool for Agent Lee Prime and the LeeWay agent fleet. It does not embed Agent Lee, an LLM, model weights, or unrestricted host control inside the application.

## Authority

Agent Lee is an assigned LeeWay employee and orchestrator. He may teach, answer, inspect, diagnose, recommend, and invoke approved tools according to identity, tenant, permission, approval, validation, and receipt policy.

## Current implementation

Product-profile, tenant-context, and health endpoints are implemented. Training, diagnosis, repair, voice, vision, MCP, model bindings, and tenant-data mutation tools are contract-defined but remain future governed implementation phases.
