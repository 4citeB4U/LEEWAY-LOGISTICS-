# Third-Party Spatial Provenance

The promoted Transit World contains source code derived from the MIT-licensed God's Eye View project pinned to commit b210ab0fe4d71c7faa0268134e0aa5f3c53fc7fe.

The original project includes or references third-party datasets and assets with separate terms. Some sources are noncommercial or attribution-sensitive.

Promotion policy:
- source/runtime code may be carried under its applicable license;
- node_modules, build output, caches, and bundled third-party event/model asset directories were excluded;
- data providers must be reviewed individually before commercial enablement;
- public-world providers remain separate from tenant-private logistics data;
- attribution requirements remain enforceable at runtime.

Do not assume the root project license relicenses third-party datasets.
