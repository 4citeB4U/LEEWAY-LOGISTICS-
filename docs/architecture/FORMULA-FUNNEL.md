# LeeWay Formula + Context Funnel for Logistics

Every consequential operation passes through: HUMAN -> DEVICE/SYSTEM -> AGENT -> INTENT -> ENVIRONMENT -> PLATFORM -> CAPABILITY -> AUTHORITY -> PERMISSION -> STATE -> HISTORY -> RISK -> CONNECTIVITY -> EVIDENCE -> RECOVERY -> ADAPTATION.

For route planning this includes vehicle dimensions, load weight, HOS, route restrictions, traffic, weather, facility approach, appointment windows, historical delays, confidence, and source freshness.

For load selection this includes revenue, total miles, deadhead, driver availability, equipment match, HOS, pickup/delivery windows, route risk, fuel/service availability, and customer/broker history.

Conceptual Formula role until canonical binding is verified: prioritize work by intent relevance, spatial proximity, route intersection, risk, freshness, confidence, and compute/network cost. Current status: PROPOSED / NOT EXECUTED.

Veritas rules: road rendered != truck-safe; GPS point != verified delivery; load posted != load contracted; contract parsed != contract accepted; HOS value present != compliant dispatch; document uploaded != document validated; employee onboarded != credentialed; world layer available != authorized.
